# SVM-only classification comparison

The three PNG files in `output/` were generated by `plot_svm_comparison.py`:

- `svm_metrics.png`: ordinary accuracy, balanced accuracy, macro F1
- `svm_confusion_matrices.png`: counts of true versus predicted labels
- `svm_recall.png`: recall for each diagnosis

Every plotted classifier is an RBF support vector machine (SVM). The 3-class
V4 run tunes its feature representation from spectral and tensor candidates
inside training folds. The binary tensor run uses TT/Tucker waveform features.
The binary direct EEG run uses conventional spectral and time features extracted
from the cleaned `.set` files, without tensor pipeline inputs.

| SVM run | Task | Accuracy | Balanced accuracy | Macro F1 | Dementia precision | Dementia recall | Dementia F1 | CN recall |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| V4 tuned RBF SVM | AD / FTD / CN | 60.6% | 59.7% | 0.589 | — | — | — | 78.2% |
| Binary TT/Tucker RBF SVM | Dementia / CN | 68.6% | 65.4% | 0.649 | 77.9% | 74.6% | 0.760 | 56.3% |
| Binary direct EEG RBF SVM | Dementia / CN | 73.1% | 71.2% | 0.704 | 82.0% | 76.8% | 0.793 | 65.5% |

The 3-class SVM recalls are 57.4% for AD, 43.5% for FTD, and 78.2% for CN.
The confusion matrices pool three held-out predictions per person over three
repeated five-fold subject-level CV runs: 264 predictions from 88 people per
method. Rows are true labels; columns are predicted labels. Diagonal cells are
correct classifications. The repeated observations are not 264 independent
people.

The new binary runs select SVM feature settings and C within three training-only
inner folds by macro F1, then dementia recall and balanced accuracy. Both use
the same 88 participants and outer split seed. The 3-class V4 SVM is an
observed classifier-family result from an earlier experiment; its features can
differ across outer folds. Three-class versus binary is a different prediction
task, so the score gap does not isolate the effect of the classifier. The binary
direct EEG SVM is lower than the earlier 78.4% logistic regression baseline;
using SVM everywhere did not improve all scores. There is no external cohort.
