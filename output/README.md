# Exported experiment artifacts

- `pdf/AIBSI_Three_Experiment_Comparison_2026-11-03.pdf`: five-page comparison of
  Graph-NTF, the four literature-method adaptations, and the separate log-mel
  SVM + EEGPT fixed-split result. Charts are generated by Matplotlib; the PDF
  builder is `technical_report/build_experiment_comparison_pdf.py`.
- `csv/G_NTF_174_Participants_5_Features.csv`: 174 participant rows containing
  `participant_id`, `diagnosis`, `source`, `site`, and five standardized component
  features. Only the five component columns are classifier features. Metadata
  and diagnosis columns are not predictors.

The CSV reproduces the final full-cohort Graph-NTF model's SVM input after saved
site centering and standardization. Values were checked against
`neural_comparison/graph_ntf_svm/outputs/full/final_gntf/svm_input_matrix.npy`.
Negative standardized values are expected. These are not the raw non-negative
component activations.

The final model was fitted to all 174 people. Do not split this CSV into new
train/test folds and claim an unbiased tensor-pipeline evaluation: fit the
decomposition and all learned transformations inside each training fold instead.
Use the benchmark scripts for participant-disjoint evaluation.

No raw EEG recordings or model checkpoints are included in these exports.
