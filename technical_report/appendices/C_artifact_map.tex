\section{Canonical versus historical material}

The canonical controlled data are under
\path{preprocessing/04_clean_primary/primary}. The V3/V4 full-cohort analysis
uses a separate index over stage-02 primary and leftover arrays; it does not
replace the controlled partition. The original
\path{preprocessing/reports/README.md} and
\path{tensor_pipeline/README.md} are historical snapshots and include statements
that became stale after later experiments. The \code{00\_CURRENT\_INDEX.md}
files and this report provide current navigation.
